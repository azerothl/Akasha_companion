# Akasha Companion

Akasha Companion est un client vocal pour le daemon Akasha sur la carte ESP32-S3 Freenove FNK0104B. Il capture et restitue l’audio et affiche l’avatar sur son écran.

## Matériel et échanges

Le client communique avec le daemon sur le réseau local. Le daemon assure la transcription, la synthèse et l’exécution des outils. Pour préparer un firmware ou une intégration, vérifier le profil matériel et le contrat API avant de provisionner la carte.
